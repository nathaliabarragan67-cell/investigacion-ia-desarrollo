# Investigación en IA y diseño de sistemas de software

Portafolio de investigación del **Semillero de Ingeniería y Desarrollo de Software** del Politécnico Grancolombiano.

## Sobre mí

Soy **Nathalia Barragán Torres**, estudiante de Ingeniería de Software (tercer semestre). Este repositorio documenta mi proceso de investigación sobre cómo la inteligencia artificial está cambiando la forma de desarrollar software.

## Pregunta de investigación

> Si la habilidad más valiosa ya no es dominar muchos lenguajes de programación, sino saber **diseñar y estructurar sistemas** y elegir las herramientas correctas, ¿cómo se le comunica un diseño a una IA para que lo construya bien?

## Líneas de investigación

1. **Fundamentos:** qué son los LLM, los agentes y los copilotos de IA, y en qué se diferencian.
2. **Diseño de sistemas:** cómo especificar requisitos y arquitectura para que una IA genere el código.
3. **Herramientas:** pruebas y comparaciones de herramientas como Claude Code y otros asistentes de programación.
4. **Riesgos y calidad:** errores, seguridad y forma de revisar el código generado por IA.

## Estructura del repositorio

## Metodología

- Cada lectura tiene una **ficha**: referencia, resumen, aportes, limitaciones y opinión propia.
- Cada herramienta se **prueba con una tarea real** y se documenta el resultado.
